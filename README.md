# 段考小幫手・時鐘置頂版

考場用的大型倒數時鐘展示頁，單一 HTML 檔即可運作，可透過 GitHub Pages 或 Google Apps Script 部署，也能離線帶著走。老師在後台排好考程、貼上學生名單，展示畫面就會自動顯示目前時鐘、考前提醒、今日考程與出缺席統計。

## 功能特色

- **大型時鐘**：指針式／數字式兩種樣式，可調大小（特大／大／中／小）與位置（靠上／置中），支援四方向微調與快速校時。
- **考程管理**：新增／編輯／刪除考程，同科目防重複排定；支援上傳 PDF 自動辨識考程（純本機解析，不上傳任何資料）。
- **考前提醒**：三階段提醒（第一次／強／最後）可各自設定分鐘數與訊息文字，並可選擇語音播報。
- **出缺席**：應到／實到／缺席即時統計，缺席名單支援手動新增與勾選學生名單。
- **學生名單**：批次貼上姓名自動編號，或手動新增／修改／刪除單一學生，卡片式呈現。
- **離線使用**：「下載離線使用檔」會把目前的名單、考程、出缺席、提醒與時鐘設定全部內嵌進單一 HTML，帶到沒有網路的裝置也能直接開啟繼續使用；所有資料只存在使用者本機（`localStorage`），不會上傳到任何伺服器。
- **設定備份**：可匯出／匯入設定 JSON，方便在多台裝置間同步或還原。

## 使用方式

### 方式一：GitHub Pages

直接開啟 GitHub Pages 網址即可使用（見 repo 的 Pages 設定）。

### 方式二：Google Apps Script 網頁應用程式

1. 將 `Code.gs` 與 `index.html` 上傳到 Google Apps Script 專案。
2. 部署為網頁應用程式（`doGet()` 會回傳 `index.html`，並允許在 iframe 中嵌入）。

### 方式三：離線單一檔案

在設定頁「離線使用」分頁下載離線使用檔後，直接用瀏覽器開啟該 HTML 檔即可，不需要網路連線與伺服器。

## 資料與隱私

所有名單、考程、出缺席與設定都只儲存在瀏覽器的 `localStorage`，不會上傳到任何外部服務；PDF 考程解析也完全在瀏覽器內完成，不會把檔案內容傳送出去。
