# 段考小幫手：設計規範

> 狀態：定案（v2.29.0）。最後更新：2026-10-25。改任何頁面、版面、元件、樣式前先讀這份。要偏離，先更新本文件並取得使用者確認。

- 定案畫面：`index.html` 本身就是模擬頁（單一檔案、無外部資源，直接用瀏覽器開啟即可看到每個畫面）。設計討論過程用的私人預覽頁不入庫。
- 樣式位置：`index.html` 的 `<style>` 末段，「設計系統層 v2.29」與「後台資訊架構（v2.29）」兩個區塊；其上是歷史樣式，後者覆蓋前者。新樣式一律用本文件的 token。
- 範圍：只改視覺、版面與操作層級。功能、資料格式、計時與省電邏輯不在此範圍。

## 1. 設計原則

1. **深色唯一，主畫面背景一律純黑 `#000`。** 教室 85 吋大屏要省電、不發熱；使用者 2026-10-25 決議不做淺色與切換開關。
2. **桌機顯示優先，手機與 iPad 只負責設定與排考程。** 兩者衝突時桌機優先；設定介面在手機要單手好按（點擊區 ≥ 44px）。
3. **主畫面只做減法。** 資訊（科目、倒數、數字）最亮，操作鈕退到第二層；不動版面比例、尺寸與「量到再縮」。
4. **後台依任務分組，少用的收合。** 每張卡最多一個實心主按鈕；風險動作降成文字鈕並保留確認。
5. **單一 HTML、無外部依賴、可離線。** 只用系統字型；不載入 CDN、外部字型或圖片。

## 2. Tokens

只有深色，沒有淺色欄。token 定義在 `:root`。

### 色彩

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#000` | 主畫面所有大面積背景、卡片、時鐘面（不可改） |
| `--s1` | `#05080d` | 設定視窗底、輸入框底、對話框底 |
| `--s2` | `#0a1119` | 設定視窗內的卡片 |
| `--s3` | `#101a26` | 按鈕、晶片、提示框 |
| `--s4` | `#182534` | 按下、目前分頁、步驟圓圈 |
| `--line` | `#526071` | 主畫面卡片框線（2px） |
| `--line-soft` | `#263548` | 設定視窗分隔線、卡片框 |
| `--line-mid` | `#3a4d66` | 按鈕與輸入框框線 |
| `--line-hi` | `#5b7391` | 滑過、勾選框 |
| `--text` | `#d8e0e8` | 內文（刻意不是純白，避免大屏刺眼） |
| `--text-hi` | `#eef3f8` | 標題、按鈕字 |
| `--muted` | `#94a3b8` | 次要說明、區塊標題 |
| `--blue` | `#38bdf8` | 強調、焦點、考程分頁 |
| `--green` | `#6ee7a0` | 進行中、已儲存、學生與缺席分頁 |
| `--yellow` | `#e8c85b` | 下一科、提醒 |
| `--orange` | `#e79a57` | 出缺席 |
| `--red` | `#ef6680` | 缺席、刪除 |
| `--primary` / `--primary-hi` | `#0369a1` / `#7dd3fc` | 主按鈕底／框 |
| `--danger-bg` / `--danger-line` / `--danger-ink` | `#2a0a14` / `#9f1239` / `#ffb4c0` | 危險按鈕 |

狀態色只表示狀態：綠＝進行中，黃＝下一科與提醒，橘＝出缺席，紅＝缺席與刪除。文字對比皆 ≥ 4.5:1。

### 字型

| 用途 | 字型 | 備註 |
|---|---|---|
| 一般 | `Inter, "Noto Sans TC", "Microsoft JhengHei", sans-serif` | 沿用，不新增字型 |
| 時間與數字 | `ui-monospace, Consolas, monospace` | 時間範圍、倒數、出缺席數字 |

設定視窗字級：頁標題 1.35rem、卡片標題 1.1rem、內文 1rem、說明 0.85rem、區塊標題（摺疊）1.05rem。主畫面沿用原本的 `clamp()` 字級，不改。

### 間距、圓角、點擊區、動態

| token | 值 |
|---|---|
| `--r-sm` / `--r-md` / `--r-lg` | 8px（按鈕、輸入）／12px（小區塊、摺疊）／18px（卡片、視窗） |
| `--hit` | 滑鼠 40px；觸控或 ≤ 900px 為 44px |
| `--pad` | 設定視窗左右內距：24px；≤ 700px 為 16px |
| `--head-h` | 設定視窗標題列高：68px；≤ 700px 為 64px |
| 間距 | 4 的倍數（4／8／12／16／20／24） |
| 動態 | 不新增動畫。只有：按鈕按下縮放（原有）、方向鍵滑過淡入（0.2 秒 opacity） |

## 3. 版面與斷點

**首頁（主畫面）**：> 900px 為上 60／下 28 兩列；上列左 45／右 55；下列三張卡（考程 1.35／出缺席 0.75／缺席名單 1）。≤ 900px 單欄堆疊；橫向手機與直向平板（700–900px）時鐘與資訊卡左右並排。這些比例已用 840 個時鐘情境驗證，不要改。

**設定視窗**：

| 寬度 | 導覽 | 視窗 |
|---|---|---|
| ≥ 1000px | 左側欄 200px（色點加文字），內容區最寬 1320px | 置中卡片，圓角 18 |
| 701–999px | 頂部分頁列，黏在標題列下 | 置中卡片（≥ 901px）或滿版 |
| ≤ 700px | 固定在底部的 4 格分頁列 | 滿版，標題列黏頂 |

**對話框（校時、修改考程、新增缺席者）**：> 700px 置中；≤ 700px 為底部抽屜（圓角在上）。

## 4. 元件規則

- **按鈕**：主（實心 `--primary`，每張卡最多一個）、次（`--s3` 外框）、文字（`.quiet`，透明，用於「清除」「清空清單」）、危險文字（`.quiet.danger`，紅字，用於清除全部考程、清除名單、回復預設）。刪除按鈕在列表列內用外框紅字。最小高度 `--hit`。
- **輸入框**：底 `--s1`、框 `--line-mid`；焦點為 `--blue` 框加 3px 淡藍光圈。高度 `--hit`。
- **晶片 `.chip`**：年級、科目、時長選擇。選中為主按鈕色；已排定科目淡化加刪除線且不可點。
- **設定卡 `.setting-card`**：底 `--s2`、1px `--line-soft`、圓角 18。標題 1.1rem。
- **步驟 `.step`**：左邊 28px 圓形序號，只用於真正有順序的流程（新增考程：日期、科目、時間）。
- **收合 `.more`**（`<details>`）：低頻功能，如管理科目、休息時間偏好、貼上或新增名單。標題列 `--hit` 高、右側箭頭。
- **摺疊區塊 `.acc`**：學期設定專用。標題列左為名稱、其下為目前設定摘要；點開才編輯。摘要由 `renderSemesterSummary()` 產生，欄位變動時即時更新。
- **危險區 `.danger-zone`**：卡片最底，上方細線，只放文字危險鈕。
- **儲存列 `.save-bar`**：學期設定頁底部黏住；提醒、考後自習、慶祝要按儲存，時鐘樣式選了就生效。
- **首頁考程列**：進行中標籤綠、下一科標籤黃；「修改」「刪除」為低調外框，刪除只有紅字。
- **時鐘方向鍵**：半透明（0.55），滑過或聚焦才完整；尺寸與位置不變（版面稽核依賴）。

## 5. 頁面規則

| 頁面 | 順序 | 備註 |
|---|---|---|
| 首頁 | 時鐘卡、資訊卡；考程、出缺席、缺席名單 | 時鐘卡上的按鈕叫「校時」，右下工具列的叫「設定」，不可同名 |
| 設定／考程 | 頁面說明、班級列；左新增考程（①日期 ②科目 ③時間），右全部考程與匯入考程表 | ≤ 900px 清單在前、表單在後；清單標題旁有「＋ 新增考程」捲到表單 |

| 設定／學期設定 | 考前提醒與語音、考後自習、考試結束慶祝、時鐘樣式與顯示；底部儲存列 | 預設全部收合 |
| 設定／備份與離線 | 離線使用檔、設定備份；危險動作在最底 | |
| 設定視窗／授權說明 | 一句話看懂、資料與隱私、免責聲明、如何申請、完整條款 | 應用程式內的獨立一頁（`#license-modal`），只從設定視窗底部進入、右上「返回」；不連外部網站；文字須與 LICENSE.md 同步 |

## 6. 文案語氣

台灣繁體中文。按鈕用動詞（「儲存考程」「下載離線使用檔」）。會刪除或覆蓋資料的按鈕結尾加「…」，點下去仍用確認視窗。說明文字簡短，不寫「請注意」之類的填充語。頁面標題用任務名稱，不用技術名稱。

## 7. 無障礙

文字對比至少 4.5:1；點擊區至少 `--hit`；鍵盤焦點一律可見（2px `--blue` 外框）；摺疊按鈕帶 `aria-expanded`；勾選框自繪但仍是原生 `<input type="checkbox">`。

## 8. 不要做的事

- 不做淺色模式與切換開關；主畫面背景不得非黑（警示色小區塊如缺席卡的深紅底除外，已存在）。
- 不新增每秒重繪的東西，不用 `box-shadow` 模糊、漸層、`backdrop-filter`、常駐動畫。
- 不動首頁的版面比例、卡片內距與時鐘尺寸；改任何會影響尺寸的樣式前，先跑版面稽核（見 TODO.md v2.25.0）。
- 不在首頁加固定或浮動頁尾；版權句只放設定視窗底部。
- 不引入外部字型、CDN、圖片檔或建置流程。
- 不改 `APP_VERSION` 唯一來源的規則（見 TODO.md「版號規則」）。

## 9. 省電與效能守則（沿用，不可退步）

來自 TODO.md v2.24.1、v2.25.0，改 UI 時不得破壞：

- 小車與進度點用 `transform` 移動，不改 `left`（避免每秒版面重排）。
- 考程清單與日期分頁內容沒變就不寫入 DOM（`setHtml`）。
- 缺席名單逐級縮字與資訊卡「量到再縮」（`fitClockFree()`、`fitInfoText()`）只在大小或內容改變時執行，不放進每秒更新。
- 煙火物理依時間計算，不依畫面更新率。
